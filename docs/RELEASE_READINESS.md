# 发布检查 · 0.1.0-alpha.1

检查日期：2026-10-13。本文件描述首个源码实验版，不能代替实际部署与实体手机验收。

## 已完成

- 从线上代码目录导出源码，排除用户会话、项目内容、邮箱目录/附件、设备配对状态、生产配置和签名密钥。清除内嵌项目截图索引，改为中性 PWA/Android 图标。
- npm 锁文件干净安装、UI 类型检查与源码构建通过；工作台合成集成测试通过。
- 新增真实 HTTP 路由认证测试、web/desktop 角色隔离、撤销配对拒绝、空目录首次启动、手机 swipe 拒绝及 Service Worker 缓存隔离测试。
- 工作台所有浏览器入口要求 Harness admission 和有效 web 配对；移除缺少转发头即放行的逻辑。
- PWA 不缓存私有页面、源码、附件和 API，升级缓存名称并清理旧版 DSH 缓存。
- Broker 与 Android 双层禁止任意坐标 swipe，防止绕过敏感按钮手动确认。
- SheetJS 使用官方 0.20.3，argparse 统一覆盖为 2.0.1，移除 sprintf-js 漏洞依赖链。npm audit 当前 0 已知漏洞。mammoth CLI --help 和 DOCX/XLSX 合成解析通过；此跨大版本覆盖应在升级依赖时继续复验，部分 npm ls 版本会按 mammoth 的旧范围显示 invalid，不能据此撤销安全覆盖。
- Android Debug 构建、上传/上传端点/状态兼容/键盘避让脚本已验证。Debug 包不作为正式发行 APK。
- 独立 Astra 审查并复查三项安全修复；实际暂存的 515 个文件（约 5.70 MB）已通过 Gitleaks 8.30.1 默认规则扫描，0 命中；个人域名、邮箱和本机路径专项扫描 0 命中。提交历史在推送前再次扫描。
